# 第 4-2 節 外部終了の原因調査（読み取りのみ。PC の設定は変更していない）

走行 `runs/v2s_trial08` の終了時刻は 2026-10-01 09:45:02、終了コード 1073807364（0x40010004、処理の木ごとの外部からの終了）。

| 時刻 | 記録（ログ、番号） | 意味 |
|---|---|---|
| 09:43:02〜09:44:29 | Application / MsiInstaller 1034・11724（Autodesk 製品の削除を 3 件、うち Autodesk Genuine Service は状態 1604） | 利用者の操作と見られるソフトの削除（推測です。起動元の記録は読み取れていない） |
| 09:45:02 | Application / Winsrv 10001「OneDrive.exe がシャットダウンを拒否しようとした」 | この時刻に Windows のシャットダウン（またはサインアウト）が始まっている。走行の終了時刻と秒まで一致する |
| 09:46:02 | System / User32 1073「chisato\chisa による再起動またはシャットダウンの試みが失敗した」、Application / Winlogon 4004「ログオン中の利用者のプロセスを終了できなかった」 | 1 回目の試みは完了せず、2 回目が走った |
| 09:47:27 | Application / Winsrv 10001（OneDrive の拒否、2 回目） | |
| 09:47:51〜09:47:58 | System / EventLog 6006、Kernel-General 13（OS の停止） | システムが停止した |
| 09:48:16 | Kernel-General 12、`LastBootUpTime` 9:48:16 | 再起動した |
| 09:49 以降 | `Code`・`codex` などのプロセスの開始時刻が 9:49 台 | Claude Code と端末を含む利用者のプロセスは、すべて再起動後に起動し直されている |

結論。走行の終了は、PC の再起動（シャットダウン）により、利用者のすべてのプロセスが終了させられたことが原因である。Claude Code や端末だけの終了ではなく、OS の再起動である。確認できたこと: 再起動の事実、その時刻、走行の終了時刻との一致、Windows Update の記録が無いこと（WindowsUpdateClient の記録 0 件）、電源喪失の記録（Kernel-Power 41）が無いこと。

わかりません: 再起動を始めたのが誰か（System / USER32 1074 の記録が見つからなかった）。ソフトの削除の完了後に利用者または削除ソフトが再起動を要求した可能性があるが、推測です。

影響。C-15 の（1）（Claude や端末を閉じても生き残る起動）は、サインアウトや再起動では生き残れない（利用者のプロセスは再起動で終了する。Task Scheduler の「ログオン時に実行」で再開する方式は設定の変更になり NOT-11 に当たる）。サインアウトを伴わない端末の終了への耐性だけを検証する。再起動の対策は報告書で提案にとどめる。
