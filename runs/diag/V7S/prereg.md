## 解釈として置いた前提（測定の前に決める）

| 項目 | 前提 |
|---|---|
| 3-3 の推定と検証の分け方 | 推定に使うのは、Low 固定（K-11 (a)）、High 固定（K-11 (d)）、基準の軌跡（Middle と停止）の 3 本。検証に使うのは、CO2 による切替（K-11 (b)）の 1 本。検証の 1 本は水準が在室中に切り替わるため、方策が使う場面に最も近い |
| 3-3 の係数の決め方 | 物質収支の式では、Q_ℓ・V・g の 3 つを同時に倍にしても予測が変わらない。このため最小二乗法で決まるのは、Q_ℓ/V と g/V と C_out だけである。V を論文の幾何（737.1 m³）に固定し、Q_ℓ と g はその値から求める。予測と採否は、この固定の仕方に影響されない |
| 3-3 の誤差の対象 | 在室時間帯を「そのステップのテナントの平均在室者数 N̄ が 0 より大きいステップ」とする。予測の起点はステップの終わりの BACnet の CO2（学習時の観測と同じ値）、的は次のステップの終わりの BACnet の CO2 とする |
| 3-4 の隣接関係 | エミュレータの建物の入力データは実行形式に組み込まれていて読めないため、論文の Fig. 2 の平面図から取る。同じテナントの中で壁を共有するゾーンを隣接とする。南北のテナントの間はコアで隔てられているため、隣接はない |
| 3-4 の系統の残差 | 影響範囲の水準の ΔC は、影響範囲のゾーンの ΔC_o の和に、反事実の ΔC_res（按分されない建物全体の残差）の全額を足したものとする |
