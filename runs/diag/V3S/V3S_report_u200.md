### 1-1. J-2 の実現可否

**実現できなかった。J-5 に従い終端 1 点の標本化のまま続行した。**

`EpisodeDriver.advance(seconds)` は一時停止タイマーに秒数を書いて目標時刻まで待つが、エミュレータの内部時間刻みは 60 秒（`Shizuku2/setting.ini` の `timestep=60`）であり、60 秒の倍数でない位置で止められない。実測は次のとおりで、225 秒の要求に対して毎回 240 秒進んだ。

| 要求 | 実際 | 開始 → 到達 |
|---|---|---|
| 225 秒 | 240.0 秒 | 1999-07-21 00:00:00 → 00:04:00 |
| 225 秒 | 240.0 秒 | 00:04:00 → 00:08:00 |
| 225 秒 | 240.0 秒 | 00:08:00 → 00:12:00 |
| 225 秒 | 240.0 秒 | 00:12:00 → 00:16:00 |
| 900 秒 | 900.0 秒 | 00:16:00 → 00:31:00 |

900 秒ステップを 4 分割すると 1 ステップが 960 秒になり、二段の時間刻みと 378 ステップの構成が崩れる。設計側の判断が必要な代替案は第 9 節 Q-2 に挙げた。
