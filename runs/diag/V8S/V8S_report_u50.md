## 6. G-50 の不合格についての読み取り

| 観察 | 値 |
|---|---|
| 改善した兄弟の A_s の和（Σ A）の 50 更新の累計 | +0.0314（方策が取り込もうとした改善の大きさ。基準の C が −0.0314 動くことを期待させる） |
| 基準の C の変化（L-8）の 50 更新の累計 | **+0.0036**（わずかに悪化） |
| 更新ごとの「−Σ A」と実際の基準の C の変化の相関 | −0.004（ほぼ 0） |
| 基準の ECI | 0.7093（更新 1）→ 0.7034（更新 50）。最大は更新 21 の 0.7108 |
| 収穫の最良（兄弟の軌跡） | 更新 1（0.7100）・更新 5（0.7112）・更新 22（0.7115）。どれも兄弟の軌跡で、基準ではない |

つまり、**個々の兄弟では区間の変更で成績が良くなったのに、その変更を方策に学ばせても、次の基準の軌跡は良くならなかった**。方策の採用率は 0.96 と高く、方策は兄弟の選択を取り込めている。それでも、更新ごとの「期待される改善」（Σ A）と、実際の基準の C の変化には相関が無い（−0.004）。足し算の近似（L-8）が、この条件では成り立たない。

原因は、この記録だけでは特定できない（わかりません）。次は推測です。

| 推測です | 内容 |
|---|---|
| 1 | 兄弟の改善は、区間の中の変更が、その区間より後の経過（室温の履歴）を変えた結果でもある。方策は区間の状態と選択の対応を学ぶが、基準の軌跡の区間より後の状態は、変更が起きる前の経過で決まっており、改善の一部が基準では再現されない |
| 2 | 損失には区間の中の全判断（兄弟が確率最大のまま取った判断を含む）が入るため、区間の変更した判断が少数（12〜16 判断。区間全体の 1 割以下）のとき、更新の大部分は確率最大の選択をさらに強めるだけで、変更した判断の学習の信号が薄まる |
| 3 | 共有のパラメータの更新が、区間の外の状態の判断にも広がり、基準の軌跡の判断を変える（基準の軌跡の KL は最後に 0.011 前後）。この変化は、一部は良く、一部は悪い（相関が無い） |
| 4 | 基準が既に局所的に良い軌跡（trial08 の 1,500 更新の後）で、区間の単独の変更の改善が小さい（改善した兄弟の平均の A_s は 0.0003〜0.0007）うえ、複数の区間の同時の変更の雑音（KL 0.01）が改善の大きさより大きい |
